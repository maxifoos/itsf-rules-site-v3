# 19. Changing the Match Table

In the event that a match is cancelled, the initial flip and score shall be invalidated.

In the event that a match is moved to another table for operational reasons, the current match state shall be carried over to the new table, i.e. the score, time-out counts and any current sanctions are carried over. However, the initial flip shall be redone, with the winning team having the choice of table sides as if for the first game.
