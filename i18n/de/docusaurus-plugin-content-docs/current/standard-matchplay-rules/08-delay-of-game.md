# 8. Spielverzögerung

:::info[Übersetzungshinweis]
Diese deutsche Übersetzung wurde KI-gestützt erstellt und noch nicht von einem Muttersprachler geprüft. Im Zweifelsfall oder bei einer Streitigkeit gilt die englische Fassung.
:::

Spieler dürfen das Spiel nicht verzögern. Das Spiel sollte durchgehend verlaufen, abgesehen von den durch das Regelwerk erlaubten Pausen und Unterbrechungen. Unterbrechungen sollten ohne Verzögerung gelöst werden.

<details>
<summary>Schiedsrichtermatch</summary>

Kündigt der Schiedsrichter „Spielen!" an, muss der Spieler mit Ballbesitz den Ball ohne Verzögerung aufschlagen. Jeder Spieler, der während des Aufschlags eine Verzögerung verursacht, verstößt gegen die Regel zur Spielverzögerung.

</details>

:::danger[Regel: Spielverzögerung]
Spieler dürfen das Spiel nicht verzögern.

**Sanktion:**
- Erstmals im Spiel: Verwarnung
- Zweites Mal im Spiel: Erzwungene Auszeit
- Weitere Male im Spiel: Strafschuss
:::
