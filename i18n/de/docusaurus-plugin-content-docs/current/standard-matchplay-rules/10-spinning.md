# 10. Durchdrehen

:::info[Übersetzungshinweis]
Diese deutsche Übersetzung wurde KI-gestützt erstellt und noch nicht von einem Muttersprachler geprüft. Im Zweifelsfall oder bei einer Streitigkeit gilt die englische Fassung.
:::

:::danger[Regel: Freies Durchdrehen]
Während des aktiven Spiels darf ein Spieler nicht:

- die Drehung einer durchdrehenden, nicht unter Kontrolle befindlichen Stange beschleunigen
- die fortgesetzte Drehung einer durchdrehenden, nicht unter Kontrolle befindlichen Stange zulassen

**Sanktion:** Verhaltensverstoß
:::

:::danger[Regel: Dreh vor dem Kontakt]
Es ist unzulässig, den Ball weiterzuleiten, indem die Stange so gedreht wird, dass sie die *Schlagzone* mehr als einmal durchläuft, bevor sie den Ball trifft.

**Zuteilung:** Ballbesitz-Zuteilung 5er-Stange
:::
