# 16. Schiedsrichter und Eskalation

:::info[Übersetzungshinweis]
Diese deutsche Übersetzung wurde KI-gestützt erstellt und noch nicht von einem Muttersprachler geprüft. Im Zweifelsfall oder bei einer Streitigkeit gilt die englische Fassung.
:::

## 16.1 Eskalationsverfahren

Eskalationspunkte gelten regelübergreifend und werden pro Spiel angesammelt, wie folgt:

- Eskalation 1: Verwarnung
- Eskalation 2: Weiterspielen oder Ballbesitz-Zuteilung 5er-Stange
- Eskalation 3 und höher: Strafschuss

## 16.2 Schiedsrichteranforderung

In einem Spiel ohne Schiedsrichter kann ein Spieler während einer Spielerunterbrechung oder einer anderen Spielunterbrechung einen Schiedsrichter anfordern.

Ein Schiedsrichter kann angefordert werden, um:

- eine Regelauslegung bereitzustellen
- eine Uneinigkeit zu klären, die die Spieler nicht lösen können
- das Spiel mit einem Schiedsrichter fortzusetzen

:::danger[Regel: Unrechtmäßige Schiedsrichteranforderung]
Ein Spieler darf außerhalb einer Spielpause keinen zweiten Schiedsrichter anfordern.

**Sanktion:** Anforderung abgelehnt, Verhaltensverstoß
:::

## 16.3 Autorität des Schiedsrichters

Die Autorität des Schiedsrichters beginnt mit seinem Eintreffen am Tisch und ist während des gesamten Spiels jederzeit zu respektieren.

Die Spieler sollten sich ihrer Rechte und Pflichten bewusst sein, wenn ein Spiel unter Schiedsrichterkontrolle steht.

Amtiert ein Schiedsrichter, dürfen die Spieler das aktive Spiel nicht unterbrechen, um Verstöße zu melden oder zu diskutieren. Nur der Schiedsrichter kann das Spiel unterbrechen, um einen Verstoß zu erklären. Ein Spieler kann jedoch eine förmliche Beanstandung vorbringen, wie nachstehend dargelegt.

Als Reaktion auf einen Regelverstoß, der das aktive Spiel beeinträchtigt, kann der Schiedsrichter dem nicht fehlbaren Team stets eine Wiederholung zuteilen.

Unter bestimmten Umständen kann der Schiedsrichter die Unterbrechung des Spiels verzögern, bis das Ergebnis einer Weiterleitung feststeht.

Die Entscheidung des Schiedsrichters kann auf Informationen von Spielern, Zuschauern, anderen Schiedsrichtern und verfügbaren Videoaufnahmen beruhen.

Die Spieler werden daran erinnert, dass menschliches Versagen Teil des Spiels ist.

## 16.4 Schiedsrichteranweisungen

Die Anweisungen eines Schiedsrichters müssen während eines Spiels befolgt werden.

Die Spieler müssen mit den folgenden Ansagen vertraut sein, die ein Schiedsrichter während des aktiven Spiels machen kann:

| Ansage des Schiedsrichters | Grund | Spieleraktion |
| --- | --- | --- |
| „Stop!" | Schiedsrichterunterbrechung | Der Ball muss gestoppt und gehalten werden |
| „Zeit!" | Ballbesitzdauer-Verstoß | Der Ball muss gestoppt und gehalten werden |
| „Reset" | Geringfügiger Verstoß | Das aktive Spiel wird fortgesetzt |

Die Spieler müssen außerdem mit den folgenden Ansagen vertraut sein, die ein Schiedsrichter während einer Spielunterbrechung machen kann:

| Ansage des Schiedsrichters | Grund | Spieleraktion |
| --- | --- | --- |
| „Zeit!" | Die für die Pause zulässige Höchstdauer ist abgelaufen | Sich spielbereit machen |
| „Spielen!" | Das Spiel muss nun beginnen | Aufschlagen |

Es ist einem Spieler untersagt, das Urteil eines Schiedsrichters infrage zu stellen; dies wird als Verhaltensverstoß gewertet. Ein Spieler kann jedoch eine Entscheidung des Schiedsrichters beanstanden, wenn er glaubt, dass ein Tatsachenirrtum vorliegt oder eine falsche Zuteilung oder Sanktion angewendet wurde.

Jede Beanstandung muss erfolgen, bevor das aktive Spiel fortgesetzt wird, oder, falls das Spiel beendet ist, bevor der Schiedsrichter den Tisch verlassen hat.

## 16.5 Tatsachenbeanstandung

Ein Spieler kann eine Tatsachenbeanstandung beantragen, wenn er mit dem Schiedsrichter nicht übereinstimmt, was tatsächlich am Tisch geschehen ist, zum Beispiel ob:

- der Ball im Tor war
- der Ball eine Spielfigur berührt hat
- der Ball an der 5er-Stange übersprungen wurde

Eine Tatsachenbeanstandung kann anhand der Beobachtungen eines anderen Schiedsrichters oder, falls erforderlich und verfügbar, anhand von Videomaterial geklärt werden. Nach der Überprüfung wird die Beanstandung entweder als erfolgreich oder als erfolglos eingestuft.

:::danger[Regel: Zwei erfolglose Tatsachenbeanstandungen]
Ein Spieler darf in einem Satz nicht mehr als eine erfolglose Tatsachenbeanstandung vorbringen.

**Sanktion:** Strafschuss
:::

## 16.6 Regelbeanstandung

Sind die Tatsachen unstrittig, glaubt ein Spieler aber, dass der Schiedsrichter eine Sanktion falsch angewendet hat, kann der Spieler eine Regelbeanstandung beantragen.

Der Spieler muss genau angeben, welche Entscheidung beanstandet wird. Der Schiedsrichter kann dem Spieler entweder zustimmen und die Beanstandung annehmen, oder eine Entscheidung des Oberschiedsrichters oder des kompetentesten verfügbaren, vom Turnierbüro bestimmten Schiedsrichters einholen.

Ist die Regelbeanstandung erfolglos, hat das antragstellende Team einen Verstoß begangen und darf für den Rest des Spiels keine weiteren Regelbeanstandungen mehr beantragen.

:::danger[Regel: Erfolglose Regelbeanstandung]
Ein Spieler darf keine erfolglose Regelbeanstandung vorbringen.

**Sanktion:** Strafschuss, keine weiteren Regelbeanstandungen im Spiel erlaubt
:::

## 16.7 Strafkarten

Ein Spieler kann den fehlbaren Spieler darauf hinweisen, dass sein Verhalten untersagt ist, und ihn auffordern, damit aufzuhören. Falls erforderlich, kann der Spieler einen Schiedsrichter bitten, die Angelegenheit zu klären.

<details>
<summary>Schiedsrichtermatch</summary>

Ist der Schiedsrichter der Ansicht, dass ein Spieler gegen eine Regel verstoßen hat, deren Sanktion ein Verhaltensverstoß ist, kann er eine Strafkarte anwenden. Je nach Art des Verstoßes kann der Schiedsrichter vor dem Einsatz einer Strafkarte eine oder mehrere mündliche Verwarnungen aussprechen.

Ein Schiedsrichter, der zur Klärung eines Streits an den Tisch gerufen wird, kann einen Verhaltensverstoß auch für ein Verhalten aussprechen, das vor seiner Ankunft stattfand, sofern sich der relevante Sachverhalt feststellen lässt.

| Karte | Sanktion |
| --- | --- |
| Gelb | Strafschuss |
| Erste Rote | Satzforfait |
| Zweite Rote | Spielforfait |

Die Spieler dürfen einen Schiedsrichter, der eine Strafkarte einsetzt, nicht infrage stellen oder beanstanden.

</details>
