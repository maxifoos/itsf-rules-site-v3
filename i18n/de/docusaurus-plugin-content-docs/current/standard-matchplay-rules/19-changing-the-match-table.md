# 19. Wechsel des Spieltisches

:::info[Übersetzungshinweis]
Diese deutsche Übersetzung wurde KI-gestützt erstellt und noch nicht von einem Muttersprachler geprüft. Im Zweifelsfall oder bei einer Streitigkeit gilt die englische Fassung.
:::

Wird ein Spiel abgebrochen, werden der Anfangslosentscheid und der Spielstand für ungültig erklärt.

Wird ein Spiel aus betrieblichen Gründen auf einen anderen Tisch verlegt, wird der aktuelle Spielstand auf den neuen Tisch übertragen, das heißt, der Spielstand, die Auszeitenzahl und alle laufenden Sanktionen werden übernommen. Der Anfangslosentscheid wird jedoch wiederholt, wobei das gewinnende Team die Wahl der Tischseite hat, als handle es sich um den ersten Satz.
