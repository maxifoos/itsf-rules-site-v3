# 8. Retard de jeu

:::info[Avis de traduction]
Cette traduction française a été produite par IA et n'a pas encore été relue par un locuteur natif. En cas de doute ou de litige, la version anglaise fait foi.
:::

Les joueurs ne doivent pas causer de retard au match. Le jeu doit être continu, à l'exception des pauses et interruptions autorisées par le règlement. Les interruptions doivent être résolues sans délai.

<details>
<summary>Match arbitré</summary>

Si l'arbitre annonce « Jouez ! », le joueur ayant la possession doit mettre la balle en jeu sans délai. Tout joueur causant un retard pendant la mise en jeu enfreint la règle du Retard de jeu.

</details>

:::danger[Règle : Retard de jeu]
Les joueurs ne doivent pas causer de retard au match.

**Sanction :**
- Première fois dans le match : Avertissement
- Deuxième fois dans le match : Temps mort forcé
- Fois suivantes dans le match : Penalty
:::
