# 19. Changement de table de match

:::info[Avis de traduction]
Cette traduction française a été produite par IA et n'a pas encore été relue par un locuteur natif. En cas de doute ou de litige, la version anglaise fait foi.
:::

Si un match est annulé, le tirage au sort initial et le score sont alors invalidés.

Si un match est déplacé vers une autre table pour des raisons opérationnelles, l'état actuel du match est reporté sur la nouvelle table, c'est-à-dire que le score, le décompte des temps morts et toute sanction en cours sont reportés. Toutefois, le tirage au sort initial doit être refait, l'équipe gagnante ayant le choix du côté de table comme pour la première manche.
